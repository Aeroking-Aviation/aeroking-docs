# Glossary

Plain-English definitions of terms you'll meet across the Dashboard.

Add-on (plugin)
:   An optional feature a school can switch on, such as **Handling/PPR** or the **Departure
    Board**. If it's off, its menu doesn't appear.

ARC
:   Airworthiness Review Certificate. Tracked per aircraft as a renewal reminder.

Capability
:   A specific permission (e.g. "create invoices"). See
    [Capabilities & permissions](capabilities.md).

Check flight
:   A booking type used for a proficiency or standards check.

Compliance area
:   A monitored subject in the school's compliance programme (e.g. a standard ATO
    monitoring item). Found under **Office → Compliance**.

Experience / trial flight
:   An introductory flight, often sold as a gift voucher, for someone who isn't yet a
    member.

Hobbs / Tach
:   Two ways of measuring engine running time. Used for billing and for hours-based
    servicing reminders.

Ledger / account
:   Each member's running balance. An **append-only** record of charges, payments, refunds
    and adjustments, so a statement always reconciles.

Member rank
:   A flying member's position on the ladder — student, qualified pilot, trainee instructor,
    qualified instructor or examiner. Each rank inherits the ones below it.

Membership tier
:   The level of a member's paid membership (set by the school), with a paid-until date.

Owner
:   The school's account holder. Automatically holds every capability and manages the
    subscription.

PPR
:   Prior Permission Required — a visiting aircraft's request to use the airfield. Managed
    in the **Handling** area (an add-on).

Rate card
:   The school's catalogue of products and prices (net + VAT + gross) used on invoices,
    vouchers and parking fees.

Role
:   The broad description of who a user is — student, instructor, staff, engineer,
    administrator, etc. Sets the default menu and capabilities.

Squawk
:   A reported aircraft defect, logged in the maintenance record.

Subdomain
:   The short name in a school's web address (the `highland` in
    `highland.aerokingaviation.com`). Identifies the school's private portal.

Syllabus framework
:   The structured training standard a course is built on (e.g. the built-in EASA
    framework).

VAT
:   Value Added Tax. Invoices show a per-line net / VAT / gross breakdown.

Voucher / package
:   Prepaid value sold to a customer and redeemed against bookings — a single gift voucher
    or a multi-item package.
